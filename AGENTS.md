# Consignes pour les modifications du site

Lire [SPECIFICATIONS.md](SPECIFICATIONS.md) avant de créer ou renommer du contenu.

Les noms de fichiers des nouvelles pages et notes, les identifiants d’URL (`slug`, `routeSlug`) et les nouvelles clés `translationKey` doivent toujours être en anglais, dans toutes les langues du site. Les titres et le texte restent dans la langue du contenu. Conserver le même identifiant et le même chemin dans toutes les traductions.

Après une modification du contenu ou des adresses, lancer `npm run build`, qui vérifie aussi les liens internes. Mettre à jour le README si une procédure éditoriale change.
