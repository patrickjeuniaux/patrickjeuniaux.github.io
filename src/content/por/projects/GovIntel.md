## Questão estudada

Como utilizar os dados administrativos das bases nacionais de ADN para apoiar o seu funcionamento, a investigação e a informação forense?

## Objetivos

O projeto interno do **[INCC](/por/nicc/)** visa desenvolver um sistema de informação que permita:

- a exploração de dados e a produção de relatórios operacionais;
- o estudo da reincidência e das carreiras criminais;
- a análise de dados para informação forense.

Um consultor apoia os aspetos técnicos.
